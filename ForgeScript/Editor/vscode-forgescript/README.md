# MageCap ForgeScript for Visual Studio Code

Colors `.forge` files and auto-indents blocks. The extension and `.forge` files show the ForgeScript icon
(file icon themes that draw their own icon for `.forge` files keep theirs).

## Install (step by step)

1. Close Visual Studio Code.
2. Copy this whole `vscode-forgescript` folder into your VS Code extensions folder:
   - Windows: `C:\Users\<your name>\.vscode\extensions\`
   - Linux: `~/.vscode/extensions/`
3. Open Visual Studio Code again.
4. Open any `.forge` file. The language name in the bottom-right corner should say **ForgeScript**.
