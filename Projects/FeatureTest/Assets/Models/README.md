# Test models

WaterBottle and Lantern come from the [Khronos glTF Sample Assets](https://github.com/KhronosGroup/glTF-Sample-Assets)
repository. Both are released under **CC0 1.0 Universal** (public domain), so they are safe to ship.
SkinnedColumn is Bellows' own, written by `Tools/GenerateTestModels.py` (a 2 m column with two bones
and the clips "Bend" and "Wave").
