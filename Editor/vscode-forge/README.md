# Forge Language for Visual Studio Code

Colors `.forge` files and auto-indents blocks.

## Install (step by step)

1. Close Visual Studio Code.
2. Copy this whole `vscode-forge` folder into your VS Code extensions folder:
   - Windows: `C:\Users\<your name>\.vscode\extensions\`
   - Linux: `~/.vscode/extensions/`
3. Open Visual Studio Code again.
4. Open any `.forge` file. The language name in the bottom-right corner should say **Forge**.
