# MageCap Bellows 0.4.0

The editor learns to lay out game UI on the game's own screen, ForgeScript warns about likely
mistakes, and the editor's automation connection is hardened after MageCap Bellows' first audit.

Download `MageCap-Bellows-0.4.0-Windows.zip` below, unzip it anywhere and open `START HERE.txt`.
Everything is included (Python too); you need a graphics driver with Vulkan 1.3.

These notes grow as 0.4.0's work lands; builds until the release report `0.4.0-dev`.

## Editor UI tools

- **The UI view** (the viewport toolbar's layout button, or **View → UI View**): in edit mode the
  viewport shows the game's screen at a chosen size (**View → UI View Size**: 720p to 4K,
  ultrawide, 4:3, portrait or your own), fitted and letterboxed, through the game camera. Clicks
  select the UI element under the pointer.
- **Handles on the selected rect**: drag it to move it, its edges and corners to resize it, and its
  green anchor markers to move its anchors while it stays put. Hold **Ctrl** to snap (8 reference
  pixels, anchors to 0.05). Each drag is one undo step; a rect a UI Layout places shows its outline.
- **Anchor presets** in the Inspector's UI Rect: a grid of the 16 presets. A click keeps the rect
  where it is; **Shift**+click moves it to the preset.
- Automation: `bellows.editor.set_ui_view()` and `ui_view()`.

## ForgeScript 1.4.1

- **Warnings**, which never stop a script: a value named like a built-in function the script also
  calls (`set max to 10`, then `max(3, 4)`), and a phrase written with brackets (`hide (menu)`),
  which calls a function instead.
- `forgescript --check` reads `forgescript-api.json` like the language server, so it reports
  exactly what the editor shows, engine phrases included.
- A `match` with no `is` choice gets one clear message.
- Nesting deeper than 256 levels is a mistake with a clear message, instead of crashing the
  checker; deeply nested files check much faster.
- `docs/ForgeScript/Specification.md`: the exact rules of the language.

## Security

- **The agent server** (the editor's automation connection on `127.0.0.1:7420`) uses a 64-digit
  token from the system's secure random source, compares it in constant time, refuses anything a
  browser sends, keeps its session file readable only by you on Linux, and serves each client on
  its own.
- **Python imports**: a game's `Assets` folder comes after Python's standard library and the
  engine's modules, so a game file can't stand in for them, and `--check-script` on a `.py` file
  runs none of the project's code.

## Fixes

- A `wait_frames` agent request with a bad `frames` value is answered with an error instead of
  stopping the editor's frame.

## Upgrading

Projects from 0.3.x open unchanged.
