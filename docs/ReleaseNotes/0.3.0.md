# MageCap Bellows 0.3.0

The foundation release: scripts reload while the game runs, talk to each other across languages,
read named input actions and play through audio buses, and ForgeScript gets a language server and a
debugger in the Script Editor.

Download `MageCap-Bellows-0.3.0-Windows.zip` below, unzip it anywhere and open `START HERE.txt`.
Everything is included (Python too); you need a graphics driver with Vulkan 1.3.

## Scripting

- **Hot reload.** Save a ForgeScript or Python script while the game is playing and the new code
  runs right away. Script variables keep their values; ForgeScript runs `when reloaded`, Python
  calls `on_reload()`. A script with a mistake keeps running its old version and reports the mistake.
- **Script events across entities and languages.** `trigger door opened with self` in ForgeScript
  reaches every script: ForgeScript `when door opened with who` and Python
  `on_event(self, name, *values)`. Python sends with `bellows.emit("door opened", self.entity)`.
- **Input actions.** Name your controls once in **Project Settings → Input** (keys, mouse buttons
  and gamepad buttons) and read them with `is_action_down/pressed/released("jump")`. New projects
  start with move, jump, interact and pause. Gamepad buttons work directly too.
- **Audio buses.** Master, Music and Effects, each with a volume and mute, in Project Settings and
  from scripts (`set_bus_volume`, `set_bus_muted`, `play_sound(path, volume, bus)`); an Audio
  Source picks its bus in the Inspector.
- **Screenshots from games.** `save_screenshot(path="", max_width=1920)` saves what the game camera
  sees, and `user_folder()` is the game's own folder in the player's user data. MageCap Forge's
  Forge Link add-on uses them for bug reports.

## Script Editor

- **ForgeScript completion and hover help** from the ForgeScript language server: engine
  functions, phrases and your own names with their signatures and docs, as you type, after "." or
  with Ctrl+Space. Hover a name for its full signature.
- **ForgeScript debugger.** Click left of a line (or press F9) to add a breakpoint, then play.
  When a script reaches it the game pauses, the Script Editor shows the line and the new
  **Debugger** panel shows the call stack and every variable. Continue (F5), Step Over (F10),
  Step In (F11), Step Out (Shift+F11), or stop at the next line that runs.

## Materials

- **OpenEXR (.exr)** images work as material textures and as skies (drop one on the viewport).
- **Separate Roughness and Metallic maps**, so downloaded PBR texture sets work as they are,
  alongside the combined metal-rough map.

## Tools

- `forgescript --lsp`: a language server for any editor (completion, hover, mistakes as you type,
  go to definition). MageCap Forge's Chisel uses it.
- `forgescript-api.json` describes the whole engine API for tools; it ships next to the programs.
- Editor automation (`bellows.editor`) can drive the debugger: `set_breakpoints`, `debug_state`,
  `debug_continue`, `debug_step_over` and more (see `Docs/EditorAutomation.md`).
- Every build now says which commit it was made from: in **Help → About**, the Project Manager,
  the log, `Install.json` (`EngineCommit`) and, between releases, the download's name
  (`MageCap-Bellows-0.3.0-3f8b735-Windows`).

## Upgrading

Projects from earlier builds open as they are. Projects made before 0.3 have no input actions until
you add them in Project Settings.
