# MageCap Bellows 0.3.1

A small update: ForgeScript 1.2.0 with an outline and signature help for code editors, and
ForgeScript's own icon.

Download `MageCap-Bellows-0.3.1-Windows.zip` below, unzip it anywhere and open `START HERE.txt`.
Everything is included (Python too); you need a graphics driver with Vulkan 1.3.

## ForgeScript 1.2.0

- `forgescript --lsp` gives code editors an **outline** of a script (functions, phrases, kinds with
  their fields and functions, `when` handlers, script variables and constants) and **signature
  help**: while you type a call, the function's parameters with the one you are on marked. It works
  for the script's own functions, the engine's functions and methods, and the built-in ones.
  MageCap Forge's Chisel and the VS Code extension can use both.
- **ForgeScript's icon**, a smith's hammer and a speech bubble in the MageCap family's style, is on
  `forgescript.exe` and the VS Code extension.

The full list is in `Docs/ForgeScript/CHANGELOG.md`.

## Editor

- `.forge` files show ForgeScript's icon in the Content panel, so they stand out from Python
  scripts at a glance.

## Tools

- A new test, `BellowsPackageTest`, builds a release package and runs it: everything the programs
  load must be in it, the packaged game must pass the full feature test, and the packaged editor
  must export a game that starts. It guards the download against a missing file.

## Upgrading

Projects from 0.3.0 open as they are.
