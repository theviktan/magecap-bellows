# Code review checklist

Review `git diff --staged` (and new files) as a strict reviewer would. Fix everything you find,
then re-run the tests.

## Correctness
- [ ] Edge cases: empty scenes, missing files/assets, destroyed entities, play/stop/undo during
      the operation, zero-size viewports, headless mode (no window, no audio device).
- [ ] User input (files, scripts, agent requests) can never crash the editor or runtime:
      errors are logged, raised as Python exceptions, or returned as `false`.
- [ ] GPU resources: no per-frame allocations that leak; barriers/states correct; the change is
      clean under Vulkan validation (`BellowsGpuTests`, `--validation`).
- [ ] Threading: engine state is touched only on the main thread (the agent server queues work).
- [ ] Undo: editor changes to the scene go through `CommitChange`; play mode never edits the
      edited scene.

## Style (see AGENTS.md)
- [ ] Hazel naming (`PascalCase`, `camelCase` locals, `m_`/`s_`/`c_`), tabs, Allman braces,
      namespaces indented, include order.
- [ ] Comments explain why; no commented-out code, TODO placeholders, debug logging or dead code.
- [ ] Headers are self-contained and include only what they use.
- [ ] Python follows PEP 8; GLSL follows the shader conventions.

## Tests and docs
- [ ] New behavior has tests; bug fixes have a regression test.
- [ ] Python API changes: `FeatureTest.py` + `docs/ScriptingAPI.md`.
      Editor automation changes: `EditorAutomationTest.py` + `docs/EditorAutomation.md`.
- [ ] All ctest suites pass (`bellows-build-and-test`), with no new warnings.
- [ ] README/AGENTS.md/skills still describe reality.

## Repository hygiene
- [ ] No build output, `__pycache__`, logs, `.bellows/` folders, editor layout files or
      personal paths committed. Generated sample assets are regenerated by their tool.
- [ ] New third-party code or assets: compatible license, submodule or attributed asset,
      entry in `ThirdPartyNotices.md`.
- [ ] Commit message: short imperative summary, blank line, what and why.
